# Discovering Apex

## 📖 Overview

This chapter introduces Apex as the programming language used to implement business logic on the Salesforce platform. It explains that Apex is not just a programming language but a way to translate business requirements and software design into working applications.

---

## 🎯 Learning Objectives

After completing this chapter, I learned to:

- Understand the purpose of Apex.
- Create Apex classes.
- Create meaningful methods.
- Use parameters in methods.
- Return results from methods.
- Follow engineering principles while writing Apex code.
